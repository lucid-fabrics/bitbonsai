# BitBonsai v0.1.0

Released 2026-07-20 from commit `main`.

Pull the image:
```
docker pull lucidfabrics/bitbonsai:0.1.0
```

Install via Unraid:
1. Settings -> Community Applications -> "Template repositories" -> add:
   `https://raw.githubusercontent.com/lucid-fabrics/bitbonsai/main/apps/dist-unraid/0.1.0/template.xml`
2. Apps tab -> search "BitBonsai" -> Install.
